# COSC 219 Lab 4 – JavaScript Fundamentals

## About the Game

For this lab, I worked on a word guessing game using JavaScript. The player has to guess letters to figure out the hidden word. The game starts with 6 lives, and each wrong guess takes away one life. If the player guesses the word correctly, they win and get a score.

## Part A – What I Learned

One thing that surprised me was Boolean("false")`. I thought it would give false, but it actually gives true. I learned that JavaScript treats a string with text in it as true, even when the text says "false".
